# Renev Medication

**This is the API that is called from the Renev Medication app; feel free to check everything out. The domain for this API is api.medication.renev.nl.**

## Usecases
- Indicate that a new update is available
- Block a version to ensure that a discovered bug cannot reach more people, to prevent data loss
- Specify a minimum support version for the app so that the app indicates that support is only available for newer versions
- Retrieve links to funding platforms, so that the correct platforms and links are always available in the app
- Retrieve platforms through which contact can be made for support, and report bugs
